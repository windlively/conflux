下载

默认下载目录 新建任务时自动填入，弹窗里还能改；留空则跟随系统下载目录。
{{ settings.downloadDir() || '跟随系统默认' }}
默认连接数 新任务默认开这么多条连接，弹窗里可以改。
{{ settings.connections() }}
单任务上限 一个任务最多能开这么多条连接，新建任务时填不过它。
{{ settings.maxTaskConnections() }}
总连接数上限 所有任务合计，同时在用的连接不超过这么多条，超出的通道排队等空位。
{{ settings.maxTotalConnections() }}

命令行

让终端或 Agent 通过 conflux-cli 调用川流的下载引擎。

命令行工具 开启后，本机的 conflux-cli 可以把任务交给川流，和界面共用队列、连接数上限与断点续传；应用需要保持运行。关闭后 CLI 无法连接。
使用说明 可执行文件位置、常用命令和退出码。
@if (showCliHelp()) {

可执行文件

CLI 随安装包一起附带：macOS 在 Conflux.app/Contents/MacOS/conflux-cli，Windows 在安装目录下的 conflux-cli.exe。可以把它所在目录加进 PATH，下文直接用 conflux-cli。

常用命令

conflux-cli add "https://example.com/file.zip" --dir ~/Downloads -c 8 --wait
conflux-cli add "magnet:?xt=urn:btih:..." --wait
conflux-cli list --json
conflux-cli status <任务 id> --json
conflux-cli wait <任务 id> --json
conflux-cli pause <任务 id>
conflux-cli resume <任务 id>
conflux-cli rm <任务 id>

说明

  • 需要川流保持运行，并在上方开启「命令行工具」；关闭开关后 CLI 无法连接。
  • 支持 http(s)、magnet:、本地 .torrent 和 ed2k:// 链接。
  • 任务会出现在应用的任务列表里，共用队列、连接数上限和断点续传。
  • --json 输出机器可读结果；wait 完成返回 0，失败/取消返回 1。
  • rm --delete-file 会删除本地文件，没有确认前不要加这个参数。
}
