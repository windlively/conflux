### 通道表重做

- 分片列改成「编号 + 范围 + 刻度点」：一排小点把整份文件等分，亮起来的那颗就是这条连接负责的片，谁下了哪一段一眼能看出来。
- 分片列收窄，省下的宽度给了进度条；完成态不再铺绿色徽标，只留安静的「✓ 完成」。
- 窗口变窄时分级收起：≤620px 隐藏速度列，≤520px 把字节数换成百分比。

### 任务列表

- 进行中的任务始终置顶，同组内仍是最新在前；新任务一提交就排到最上面。
- 下载完成的任务多了「打开文件」，直接交给系统默认程序。暂停、取消留下的是 `.part`，所以这两种状态仍只有「打开所在目录」。

### 状态栏

- 菜单栏图标旁显示当前总速度，写成 `6.8M/s`、`128K/s` 这样的紧凑形式；没有流量时只留图标。
- 点开菜单，每条进行中的任务后面跟着自己的速度；下载中速度还是 0 时显示「下载中」。
- 设置 → 系统新增「状态栏显示速度」开关，默认开启；关掉只隐藏菜单栏那串文字，菜单里的速度不受影响。
- 速度每秒刷新一次，不会让原生菜单跟着 250ms 的进度事件抖。
